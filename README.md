## 1. Лабораторийн ажлын зорилго

Энэхүү лабораторийн ажлаар Java програмчлалын хэл дээр JUnit 5 ашиглан нэгжийн тест (Unit Testing) боловсруулах, програмын функцүүдийн зөв ажиллагааг шалгах, мөн тестийн үр дүнгээр кодын алдааг илрүүлэх үндсэн ойлголтуудыг судалж хэрэгжүүлэв.

Лабораторийн хүрээнд `GradeCalculator` классыг ашиглан оюутны дүн тооцоолох функцүүдэд тест боловсруулсан. Тестүүдэд зөв оролт, буруу оролт, хязгаарын утга болон онцгой тохиолдлуудыг хамруулсан.

Мөн кодод зориудаар өөрчлөлт оруулж, мутацийн туршилт хийснээр боловсруулсан тестүүд логикийн алдааг илрүүлж чадаж байгаа эсэхийг шалгасан.

## 4. Maven тохиргоо

Төслийн `pom.xml` файлд Java, JUnit 5 болон Maven Surefire Plugin-ийн тохиргоог хийсэн.

Ашигласан үндсэн тохиргоо:

```xml
<properties>
    <maven.compiler.release>17</maven.compiler.release>
    <project.build.sourceEncoding>UTF-8</project.build.sourceEncoding>
</properties>

<dependencies>
    <dependency>
        <groupId>org.junit.jupiter</groupId>
        <artifactId>junit-jupiter</artifactId>
        <version>5.10.2</version>
        <scope>test</scope>
    </dependency>
</dependencies>

<build>
    <plugins>
        <plugin>
            <groupId>org.apache.maven.plugins</groupId>
            <artifactId>maven-surefire-plugin</artifactId>
            <version>3.2.5</version>
        </plugin>
    </plugins>
</build>
```

Java 21 орчинд ажиллуулж байгаа боловч компиляцийн хувилбарыг Java 17 болгон тохируулсан.

JUnit Jupiter нь тест бичихэд, харин Maven Surefire Plugin нь Maven командаар тестүүдийг ажиллуулахад ашиглагдсан.

## 8. Мутацийн туршилт (Mutation Testing)

Тестүүд програмын хэвийн ажиллагааг шалгахаас гадна кодод зориудаар оруулсан алдааг илрүүлж чадаж байгаа эсэхийг шалгах зорилгоор мутацийн туршилт хийсэн.

Энэ туршилтаар `letterGrade()` функцийн дараах нөхцөлийг өөрчилсөн.

**Анхны нөхцөл:**

```java
score >= 90
```

**Зориудаар өөрчилсөн нөхцөл:**

```java
score > 90
```

Ингэснээр яг 90 оноо авсан тохиолдолд A дүн өгөх ёстой логик алдагдсан.

Өөрчлөлтийн дараа тестүүдийг дахин ажиллуулахад дараах үр дүн гарсан.

```text
Tests run: 41, Failures: 2, Errors: 0, Skipped: 0

BUILD FAILURE
```

### 8.1. Амжилтгүй болсон тестүүд

| Унасан тест | Шалгасан нөхцөл | Үр дүн |
|---|---|---|
| `yesonAravA` | 90 оноо → A | expected: A, but was: B |
| `letterGradeHyazgaaruud [2]` | 90.0 оноо → A | expected: A, but was: B |

Бусад 39 тест амжилттай ажилласан.

Энэ нь тестүүд 90 онооны зааг дээрх логикийн өөрчлөлтийг илрүүлж чадсаныг харуулж байна.

Туршилтын дараа анхны `score >= 90` нөхцөлийг сэргээж, бүх тестийг дахин ажиллуулахад 41 тест бүгд амжилттай болсон.

Мутацийн туршилтын гаралтыг `results/mvn-test-mutant.txt` файлд хадгалсан.

## 10. Дүгнэлт

Энэхүү лабораторийн ажлаар JUnit 5 ашиглан Java програмд нэгжийн тест боловсруулах, тестийн үр дүнг шалгах болон параметртэй тест ашиглах талаар практик мэдлэг эзэмшлээ.

`GradeCalculator` классын хоёр үндсэн функцэд зориулан нийт 14 тестийн метод боловсруулж, параметртэй тестийн тусламжтайгаар нийт 41 тестийн тохиолдлыг амжилттай ажиллуулсан. Тест боловсруулахдаа зөв оролт, буруу оролт, хязгаарын утга болон `NaN` зэрэг онцгой нөхцөлүүдийг хамруулсан.

Ажлын хамгийн чухал хэсэг нь мутацийн туршилт байлаа. Кодын `score >= 90` нөхцөлийг `score > 90` болгон өөрчлөхөд яг 90 оноог шалгадаг хоёр тест амжилтгүй болсон. Үүний дараа анхны нөхцөлийг сэргээхэд бүх тест дахин амжилттай ажилласан. Энэ туршилтаар тест нь зөвхөн програмын хэвийн ажиллагааг шалгахаас гадна логикийн жижиг алдааг илрүүлэхэд чухал үүрэгтэйг ойлгосон.

Мөн параметртэй тест ашигласнаар олон төрлийн оролтын утгыг давхардсан код багатайгаар шалгаж болдогийг мэдэж авлаа. Ялангуяа `totalScore()` функцийн хувьд онооны хэсэг бүрийн зөвшөөрөгдөх хязгаарыг тус тусад нь шалгасан нь алдаа гарсан тохиолдолд асуудлыг олоход илүү хялбар болгосон.

Ерөнхийдөө энэ лабораторийн ажлаар нэгжийн тест боловсруулах, хязгаарын болон буруу оролтыг шалгах, мутацийн туршилтаар тестийн чанарыг үнэлэх үндсэн ойлголтуудыг практикт хэрэгжүүлж сурлаа.
